Use this board to track feature work from request through delivery. Ask AI to add
a feature, change its priority or owner, move it to another status, or record its
completion.

<Info>
  This is a static board stored in Git. AI updates the MDX file, then Mintlify
  publishes the change after it reaches `main`.
</Info>

{/* AI MAINTENANCE CONTRACT
- Keep exactly four statuses: Backlog, Planned, In progress, and Shipped.
- Assign each feature one stable ID in the form FTR-###.
- Never reuse an ID or duplicate a card when its status changes.
- Keep cards ordered by priority (High, Medium, Low), then by ID.
- Every active card must include Priority, Owner, and Next step.
- Every shipped card must include Owner, Completed, and Outcome.
- Update the visible "Last updated" date whenever this board changes.
- Replace a "No items" card when adding the first feature to a status.
- Restore a "No items" card when removing the last feature from a status.
*/}
